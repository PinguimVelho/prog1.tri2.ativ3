# Tinder de Mesas de RPG:

O projeto consiste no desenvolvimento de uma aplicação web em TypeScript semelhante ao Tinder, porém voltada para encontrar mesas de RPG. Os usuários poderão visualizar mesas e one-shots disponíveis e escolher aquelas que mais combinam com seus interesses, podendo adicionar a seus favoritos, curtir ou negar a campanha considerando informações como sistema, temática, horário, estilo de jogo e plataformas utilizadas.

A aplicação contará com cadastro de usuários, criação de mesas, filtros e interação entre mestre e jogadores. O desenvolvimento será dividido entre planejamento (Esse texto inicial, Diagrama de classes e o Mockup), implementação das funcionalidades, integração com banco de dados, testes e ajustes finais, buscando entregar uma plataforma simples, mas responsiva e fácil de utilizar.
