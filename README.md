# Tinder de Mesas de RPG:

O projeto consiste no desenvolvimento, em três meses, de uma aplicação web em TypeScript semelhante ao Tinder, mas voltada para encontrar mesas de RPG. Os usuários poderão visualizar mesas disponíveis e escolher aquelas que mais combinam com seus interesses, considerando informações como sistema, temática, horário, estilo de jogo e plataforma utilizada.

A aplicação contará com cadastro de usuários, criação de mesas, filtros e interação entre jogadores. O desenvolvimento será dividido entre planejamento, implementação das funcionalidades, integração com banco de dados, testes e ajustes finais, buscando entregar uma plataforma simples, responsiva e fácil de utilizar.
